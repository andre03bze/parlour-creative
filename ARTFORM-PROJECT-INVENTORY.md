Current commercial focus is **Belize and the Americas**; the wider portfolio is **documented international experience**. Each project's
`location` / `place` / `market` is set **only where the source documents it** — never inferred, never rewritten to fit the Belize positioning.
`market` (Belize · Canada) drives a quiet toggle on /work; projects with no documented location carry none. Homepage index = current work first
(Blue Ocean, Caves Branch, Offi) followed by five strongest international projects (Rogers Sports & Media, Forgestone, The HUB, Aquamiel, CBC election).
